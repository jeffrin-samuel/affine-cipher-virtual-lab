02 / THEORY

Affine Cipher Fundamentals

CONCEPT

What is the Affine Cipher?

The Affine Cipher is a monoalphabetic substitution cipher based on modular arithmetic. Each letter is converted into a number, transformed using a linear function, and converted back to a letter.

ENCRYPTION
E(x) = (a × x + b) mod 26

x is the plaintext value, a is the multiplicative key, and b is the additive key.

DECRYPTION
D(y) = a⁻¹ × (y − b) mod 26

y is the ciphertext value and a⁻¹ is the modular multiplicative inverse of a.

KEY CONDITION
gcd(a, 26) = 1

The value of a must be relatively prime to 26 so that its modular inverse exists.

ALPHABET MAPPING

Interactive substitution mapping

MODULAR INVERSE

Why must a be relatively prime to 26?

The modular inverse is a number that satisfies:

a × a⁻¹ ≡ 1 (mod 26)

For example, when a = 5:

5 × 21 = 105
105 mod 26 = 1
Therefore, 5⁻¹ mod 26 = 21

If gcd(a, 26) ≠ 1, the modular inverse does not exist.

N-GRAM VIEW

Scoring evidence

0%

An n-gram is a sequence of consecutive characters. For example, THE is a trigram and TION is a quadgram.

The cryptanalysis engine compares character sequences in each candidate against an embedded English n-gram frequency dataset. Common English sequences contribute higher scores, while unlikely sequences contribute lower scores.

The highest score is therefore the most likely candidate according to the scoring model, not a mathematical guarantee of correctness.

06 / SECURITY INSIGHTS

What Does the Attack Teach Us?

312

Small Keyspace

There are only 312 possible keys for a 26-character alphabet. This makes exhaustive search practical.

01

Monoalphabetic

Each plaintext letter is consistently mapped to one ciphertext letter for a given key.

⌁

Statistical Weakness

English letter and n-gram patterns can provide information useful for identifying likely plaintexts.

!

Classical Cipher

The Affine Cipher is useful for learning cryptography concepts, but it is not suitable for modern secure communication.
